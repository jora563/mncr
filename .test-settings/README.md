# Тестовые настройки

Настойки в директории предназначенны для поднятия примеров и сервисов, как для ручного
тестирования, так и в конечном итоге для автоматизированног. Существуют следующии настройки.

- llm_request_cfg.toml: Базовая настройка для примера `cargo run --examples llm-client`
- llm_client_config.toml: Базовая настройка для примера `cargo run --examples llm-client`
- ai_omni_core_settings.toml: Базовая настройка для базового сервиса `core`.
- 2026-06-19-OMNIAI-6-core-min.sql: Минимальный, на данный момент, набор данных для запуска `core` с БД. С улучшением ботов минимальный набор данных будет сокращатся, но проекты и боты обязательны.

 Чтобы запустить тестовые сервисы, или "примеры" также требуется чтобы:

 1. Работал postgresql с правильными настройками БД. (только `core`)
 2. Существовали правильные боты в телеграмме/VK и авторизация была настроена. (только `core`)
 3. Работал сервер ЛЛМ.
