# Uzor Plugin

Библиотека для интеграции с узором. Она используется для того чтобы проверять и входящии токены (jwt мокен) которые приходят с запросами на API администратора (HTTP) и API оператора (WS). Процесс проверки следующий:

1. Запрос на Keycloak чтобы подтвердить валидность токена.
2. Парзинг токена чтобы получить роль и номер пользователя (personal id).
3. Запрос в ASAA-у для получения связанных с пользователем проектов.
   - (eg https://tc-asaa.telecontact.ru/v1/employee/whats?personalId=105127)
4. Собрать объект из этого, и переслать уже в принимающий обработчик запроса.

___
## Запуск Uzor-Plugin

Чтобы этот модуль работал, он должен быть зарегистрирован в keycloak, и должен получить следующие переменные:

1. ClientId
2. ClientSecret
3. KeyCloakPublicKey
4. KeyCloakEndpoint

Эти переменные должны быть записаны в конфигурациях сервиса. Изначально их надо получить. В рамках организации TELECONTACT для их получения нужно создать заявку на Jira ITHELPDESK.
