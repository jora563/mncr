# DB

AIOMNI DB это библиотека базовой логики SQL БД AIOMNI. Она написана на Rust. На основана на библиотеке [`sqlx`](http://docs.rs/sqlx) данный момент она работает с postgresql 16, но достаточно быстро адаптируется на mysql или sqlite.

___
## Сборка

Для сборки требуется чтобы был установлен Rust с необходимыми компонентами. Для тестирования требуется postgresql и правльно настроенные БД.

1. Зайти в корневую директорию проекта.
2. Запустить: `cargo fmt -p db --all-targets` для проверки форматирования и токенизации. `-p db` значит что только библиотека `db` будет собрана. 
3. Запустить: `cargo clippy -p db --all-targets` для проверки сборки. `clippy` также даёт советы на счёт стилистики и "не очень хорошего кода". `--all-targets` обеспечивает проверку всех бинарных артефактов библиотеки, включая тестов, библиотек и примеров.
4. Запустить `cargo test -p db` чтобы запустить все тесты.

Для тестов нужно удостоверить что правильный набор БД создан.

Надо чтобы существовал пользователь `aio_core`.
```sql
CREATE USER aio_core WITH SUPERUSER PASSWORD 'password';
CREATE DATABASE aio_core;
ALTER DATABASE aio_core OWNER TO aio_core;
GRANT ALL ON DATABASE aio_core TO aio_core; 
```

Надо также удостоверится что под `aio_core` создать БД `ai_omni_test_db_0`. Тогда можно запустить тесты.
