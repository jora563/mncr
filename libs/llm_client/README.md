# LLM Client

AIOMNI LLM Client это библиотека для взаимодействий с ЛЛМ серверами. Она написана на Rust и пользуется библиотекой [`reqwest`](http://docs.rs/reqwest) для взаимодействий с серверами.

___
## Сборка

Для сборки требуется чтобы был установлен Rust с необходимыми компонентами. Для правильной работе примера `llm-client` нужно чтобы можно было достучаться до сервера ЛЛМ.

1. Зайти в корневую директорию проека.
2. Запустить: `cargo fmt -p llm-client --all-targets` для проверки форматирования и токенизации. `-p llm-client` значит что только библиотека `llm-client` будет собрана. 
3. Запустить: `cargo clippy -p llm-client --all-targets` для проверки сборки. `clippy` также даёт советы на счёт стилистики и "не очень хорошего кода". `--all-targets` обеспечивает проверку всех бинарных артефактов библиотеки, включая тестов, библиотек и примеров.
